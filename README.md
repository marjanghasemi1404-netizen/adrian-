# وب‌سایت دبستان پسرانه غیردولتی آدریان

این پروژه یک وب‌سایت کامل، حرفه‌ای و **بدون نیاز به Backend** برای دبستان آدریان است.

## چرا React/Vite نه، بلکه HTML/CSS/JS ساده؟

پروژه به‌صورت **HTML + CSS + JavaScript ساده** ساخته شده، نه React/Vite. دلیل این تصمیم:

- محیطی که این پروژه در آن ساخته شد به اینترنت دسترسی نداشت، بنابراین امکان نصب پکیج‌های npm و تست واقعی `npm install` / `npm run build` وجود نداشت. تحویل یک پروژه React ساخته‌نشده و تست‌نشده با ریسک خطا، خلاف خواستهٔ شما (تحویل پروژه‌ای واقعی و بدون نقص) بود.
- یک سایت Static ساده:
  - **بدون هیچ نصب یا Build** باز می‌شود — کافی است فایل `index.html` را در مرورگر باز کنید.
  - مستقیم و بدون تنظیمات اضافه روی **GitHub Pages** منتشر می‌شود.
  - برای شخصی که برنامه‌نویس نیست (مطابق خواسته شما)، ویرایش متن‌ها و عکس‌ها **ساده‌تر از یک پروژه React** است؛ چون فقط یک فایل متنی (`js/data.js`) را ویرایش می‌کنید.

اگر همچنان نسخه React + Vite را لازم دارید، بگویید تا کدهای منبع را هم به همین شکل بسازم؛ فقط توجه داشته باشید که در آن صورت اجرای `npm install`/`build` را خودتان (در سیستمی با اینترنت) باید تست کنید، چون من در این محیط امکان تست آن را ندارم.

## ساختار پروژه

```
adrian-school/
├── index.html              ← صفحه اصلی سایت (ساختار HTML)
├── css/
│   └── style.css           ← تمام استایل‌ها و طراحی سایت
├── js/
│   ├── data.js              ← ⭐ همه متن‌ها، اطلاعات تماس، اخبار و گالری اینجاست
│   └── main.js              ← کدی که صفحه را از روی data.js می‌سازد (نیازی به ویرایش ندارد)
├── assets/
│   └── images/
│       ├── brand/           ← لوگوی سفید/سیاه و فاوآیکون
│       ├── hero/             ← عکس پس‌زمینه بخش Hero
│       └── gallery/          ← عکس‌های گالری (اصلی + بندانگشتی، عکس‌های واقعی مدرسه)
└── README.md                ← همین فایل
```

## 1) چطور سایت را اجرا کنم؟

هیچ نصبی لازم نیست. دو روش:

**روش ساده:** روی فایل `index.html` دو‌بار کلیک کنید تا در مرورگر باز شود.

**روش پیشنهادی (بدون مشکلات احتمالی مرورگر با فایل‌های محلی):**
اگر Python نصب دارید، در پوشه پروژه این دستور را اجرا کنید:
```
python3 -m http.server 8080
```
سپس در مرورگر به آدرس زیر بروید:
```
http://localhost:8080
```

## 2) چطور متن‌ها را تغییر بدهم؟

فقط فایل `js/data.js` را با یک ویرایشگر متن ساده (مثل Notepad، VS Code یا حتی TextEdit) باز کنید.
هر بخش سایت (Hero، درباره ما، چرا آدریان، برنامه آموزشی، امکانات، کادر آموزشی، اخبار، تماس) به‌وضوح با کامنت فارسی مشخص شده. متن داخل `" "` را تغییر دهید و فایل را ذخیره کنید. صفحه را در مرورگر رفرش کنید تا تغییرات را ببینید.

مثال — تغییر عنوان Hero:
```js
hero: {
  title: "آینده، از امروز ساخته می‌شود",   // ← این متن را عوض کنید
  ...
}
```

## 4) چطور عکس‌ها را عوض کنم؟

1. عکس جدید را در پوشه مناسب زیر `assets/images/` قرار دهید (مثلاً `assets/images/gallery/` برای گالری).
2. در فایل `js/data.js`، مسیر عکس قدیمی را با نام فایل جدید جایگزین کنید. مثال:
```js
about: {
  image: "assets/images/gallery/students-yard.jpg",  // ← نام فایل جدید را اینجا بگذارید
}
```

**نکته مهم:** برای سرعت بهتر سایت، بهتر است عکس‌ها را پیش از قرار دادن، به عرض حداکثر ۱۴۰۰ پیکسل و فرمت JPG با کیفیت حدود ۸۰ export کنید (با هر ابزار ساده مثل Squoosh.app یا فتوشاپ).

## 5) چطور عکس جدید به گالری اضافه کنم؟

1. عکس اصلی و یک نسخه بندانگشتی (Thumbnail، حدود ۴۸۰ پیکسل عرض) از آن تهیه کنید.
2. هر دو را در `assets/images/gallery/` قرار دهید.
3. در `js/data.js`، به آرایه `gallery.photos` یک آیتم جدید اضافه کنید:
```js
{
  thumb: "assets/images/gallery/عکس-جدید-thumb.jpg",
  full: "assets/images/gallery/عکس-جدید.jpg",
  caption: "توضیح کوتاه عکس",
  category: "جشن‌ها و رویدادها"   // یکی از دسته‌های موجود در gallery.categories
}
```
گالری و Lightbox به‌صورت خودکار عکس جدید را نمایش می‌دهند؛ فلش‌های صفحه‌کلید (← →) و دکمه‌های قبلی/بعدی هم برای آن کار می‌کنند.

## 6) چطور خبر جدید اضافه کنم؟

در `js/data.js`، بخش `news.items`، یک آیتم جدید در ابتدای آرایه اضافه کنید:
```js
{
  date: "۱۴۰۴/۰۸/۰۱",
  title: "عنوان خبر جدید",
  excerpt: "توضیح کوتاه خبر...",
  image: "assets/images/gallery/عکس-مرتبط.jpg",
}
```

## 7) کادر آموزشی

در `js/data.js`، بخش `staff.members` را با نام و سمت واقعی کارکنان جایگزین کنید. تا زمانی که اطلاعات واقعی ندارید، این بخش به‌صورت Placeholder قابل‌ویرایش نمایش داده می‌شود و روی سایت به‌وضوح به‌عنوان «نمونه» علامت‌گذاری شده است — نه اطلاعات ساختگی جا زده‌شده به‌عنوان واقعی.

## 8) چطور روی GitHub Pages منتشر کنم؟

1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً `adrian-school`).
2. تمام فایل‌های این پوشه (`index.html`, `css/`, `js/`, `assets/`, `README.md`) را در آن ریپازیتوری Push کنید:
```
git init
git add .
git commit -m "راه‌اندازی سایت آدریان"
git branch -M main
git remote add origin https://github.com/USERNAME/adrian-school.git
git push -u origin main
```
3. در تنظیمات ریپازیتوری، بروید به `Settings → Pages`.
4. در قسمت Source، شاخه `main` و پوشه `/ (root)` را انتخاب کنید و Save بزنید.
5. بعد از چند دقیقه، سایت روی آدرسی شبیه این در دسترس خواهد بود:
```
https://USERNAME.github.io/adrian-school/
```

هیچ مرحله Build ای لازم نیست؛ چون سایت از قبل به‌صورت HTML/CSS/JS آماده است.

## اتصال فرم به Google Sheet (اختیاری)

فرم همین الان به‌صورت خودکار ایمیل می‌فرستد. اگر می‌خواهید علاوه بر ایمیل، اطلاعات هر ثبت‌نام در یک Google Sheet هم ذخیره شود:

1. یک Google Sheet جدید بسازید.
2. از منوی «Extensions → Apps Script» یک اسکریپت جدید باز کنید و کد زیر را در آن جای‌گذاری کنید:
```js
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = e.parameter;
  sheet.appendRow([new Date(), data['نام والد'], data['نام دانش‌آموز'], data['شماره تماس'], data['پایه تحصیلی'], data['توضیحات']]);
  return ContentService.createTextOutput(JSON.stringify({status:"ok"})).setMimeType(ContentService.MimeType.JSON);
}
```
3. از «Deploy → New deployment → Web app» انتخاب کنید؛ در قسمت «Who has access» گزینه «Anyone» را بزنید و Deploy کنید.
4. آدرسی که به شما داده می‌شود (به شکل `https://script.google.com/macros/s/XXXX/exec`) را کپی کنید.
5. در فایل `js/data.js`، مقدار `form.sheetAction` را با همین آدرس پر کنید.
6. ذخیره کنید؛ از این پس هر ارسال فرم، هم ایمیل می‌شود و هم یک ردیف جدید در Google Sheet شما ثبت می‌شود.
